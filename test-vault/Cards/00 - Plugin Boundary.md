# Plugin Boundary

This plugin has one job: render existing Markdown files as read-only cards.

> One Markdown file is one card. One folder is one multi-card scope.

> [!IMPORTANT] Read-only guarantee
> The plugin may save its own layout settings, but it must not modify this note, its frontmatter, attachments, or path.

## Explicit non-goals

- No collection or sync
- No workflow or card state
- No AI, Agent, scripts, or skills
- No editing, moving, archiving, or deletion
